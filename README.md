# 🍳 CookStacker

CookStacker is a modern React-based recipe management application that allows users to explore, create, update, delete, and favorite recipes.  
Built with performance, responsiveness, and clean UI principles in mind.

🔗 Live Demo: https://cookstacker.netlify.app  
📂 GitHub Repository: https://github.com/Nayan129/Recipe-Maker

---

## 🚀 Features

- 🔍 Real-time Search Filtering
- ➕ Create New Recipes
- ✏️ Update Existing Recipes
- 🗑️ Delete Recipes
- ❤️ Add/Remove Favorites
- 💾 Data Persistence using localStorage
- 🖼️ Lazy Loading Images for Performance
- 📱 Fully Responsive Design
- 🌐 Client-Side Routing (React Router)
- 🚀 Deployed on Netlify

---

## 🛠️ Tech Stack

- React (Vite)

## ⚙️ Installation & Setup

Clone the repository:

git clone https://github.com/Nayan129/Recipe-Maker.git

Navigate into the project:

cd Recipe-Maker

Install dependencies:

npm install

Run development server:

npm run dev

Build for production:

npm run build

---

## 🌍 Deployment

This project is deployed using **Netlify**.

For proper React Router support, a `_redirects` file is added:

/\* /index.html 200
